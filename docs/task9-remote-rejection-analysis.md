## Why the Windows cause remains unknown

The inspect trap generated by `recoveryPayloadPrelude` in
`src/remote/windows-remote.mjs` preserves a small finite error set and converts
other exception messages into `RUNTIME_STATE_UNSUPPORTED`. Possible boundaries
include wrapper initialization/native compilation, directory opening and
attributes, file identity retrieval, ACL assertions, child enumeration/topology,
and subsequent identity/ACL rechecks. These are code-derived candidates, not
observed failures. Neither an ACL repair, a reboot, nor cleanup follows from the
current evidence. Do not weaken validation to make the inspection pass.
