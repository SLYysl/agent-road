# 第一条实录：Mac 上提要求，Windows 生成结果，Mac 收到文件

目标：让第一次听说 Agent Road 的人看懂一次完整任务。成片建议 45–60 秒；原始录制不限时，不承诺任务必须一分钟完成。

场景限定：已经配对并通过状态检查的 Mac → Windows。标题/画面注明“已接入设备上的真实任务”。本片不展示首次安装，不把内测能力说成任意两台电脑都能直接使用。

## 录制任务提示词

```text
使用这台 Mac 上已经配置好的 Agent Road，先读取使用指南和已有设备状态，不重新配对。
在我授权的 Windows 电脑中新建一个本次演示专用目录，生成一份独立 HTML 报告，
里面写上 Hello from Windows、本次运行的 UTC 时间、PowerShell 版本，以及三个演示任务的完成状态。
这些状态必须来自本次真实检查：远端脚本成功运行、HTML 文件成功写入、文件 SHA-256 已计算。
不要写入用户名、机器名、IP、设备 ID 或其他私人信息。只操作本次新建的演示文件，不安装软件，不重启。
把 HTML 下载到 Mac 的演示目录，对比两端 SHA-256；确认一致后在 Mac 浏览器打开。
若出现失败或结果未知，停止并报告，不伪造成功，也不盲目重放写操作。
```

先试跑一次评估耗时和画面，再用新的演示目录真实录一遍。目录名必须避免覆盖旧文件。需先确认设备在线；本文没有执行远端任务，不是成功记录。

## 镜头安排

| 成片位置 | 画面 | 要讲清的事 |
| --- | --- | --- |
| 0–5 秒 | Mac 浏览器展示最终报告，角标“本次运行结果预览” | 另一台电脑生成的文件回到了 Mac |
| 5–15 秒 | 切回任务开始，Mac Agent 窗口输入简短要求 | 保留已有 Agent，通过 Agent Road 使用 Windows |
| 15–35 秒 | 本次真实远程执行和结果返回 | 不是本地模拟；检查 PowerShell 输出和退出码 |
| 35–50 秒 | 文件下载、哈希相同，浏览器打开 HTML | 命令和文件往返形成闭环 |
| 50–60 秒 | GitHub 仓库地址及“免费开源 Alpha · Mac → Windows” | 想试用的双机用户申请内测包 |

录制一条完整原片，成片可剪去等待；压缩的地方标注“等待已加速/剪除”。不把不同尝试剪成一次无失败接入，不用伪造终端输出替代实录。

## 画面与录屏

- 16:9 横屏，终端/Agent 字号放大至手机观看也能辨认；先用一个 Mac 屏幕即可。
- Agent 窗口与浏览器并排或直接切换。只有能够真实同步录制时才加入 Windows 画中画，不需要为了效果额外装远程桌面。
- 开启勿扰、收起私人标签页。先检查窗口标题、命令输出、路径和通知，避免录到密钥、配对码、设备标识。
- Mac 按 Shift–Command–5，选择“录制所选部分”；根据需要选择麦克风。第一版可以不配音，后加简短字幕。
- 原片保留；公开前逐帧检查出现过的日志和系统通知。完成后先提供视频审阅，不自动发到社交平台。

录屏操作参考：[Apple 官方指南](https://support.apple.com/en-ie/102618)。
