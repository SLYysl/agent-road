## 运行前核对

通过维护者确认的交付渠道取得固定版本、文件清单和 SHA-256 校验值。交付包应标明安装／配置材料、素材、Agent 提示词、前提条件、已知限制和反馈方式。这是交付检查单，不代表此前每个旧压缩包已经包含这些文档。

Mac 使用 `shasum -a 256 /path/to/bundle.zip` 计算校验值；Windows 使用 `Get-FileHash -Algorithm SHA256 -LiteralPath 'C:\path\to\bundle.zip'`。与另行提供的校验值比较。同一压缩包里附带的哈希本身无法证明发布者身份，哈希也不是受信任代码签名。

按同一版本包内说明操作，不混用网站旧下载或旧配对码。让 Agent 先只读检查环境，再解释需要的变更并取得授权。接入前阅读 [Windows 变更与退出说明](windows-access-and-removal.zh-CN.md)。已接入用户保留原控制器状态，先查状态，不重新配对。
